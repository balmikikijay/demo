# BookMyCareer CRM — Demo Build

This is the **demo build** of the redesigned BookMyCareer College CRM
(React + TypeScript), published for demonstration only.

- **Live demo:** https://balmikikijay.github.io/bookmycareer-crm/
- **API:** https://bookmycareer-clone-api.onrender.com/api
  (demo data — resets when the free-tier backend restarts; first request
  after idle can take up to ~50 seconds)
- **Demo login:** use the demo buttons on the login screen
  (Counsellor / College). No real account is needed.
- **Note:** this is a learning rebuild with an enhanced design, built from
  the public feature walkthrough of the original CRM. It is not the
  company's real CRM and contains no real student data.
